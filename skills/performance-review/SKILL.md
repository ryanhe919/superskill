# 性能代码审查

你正在执行全面的性能代码审查。你的目标是识别和优化性能瓶颈。

## 审查重点

1. **算法效率**
   - 时间复杂度分析（O(n), O(n²), O(log n)等）
   - 空间复杂度分析
   - 识别不必要的循环嵌套
   - 算法优化建议

2. **数据库性能**
   - N+1 查询问题
   - 缺失的索引
   - 低效的 JOIN 操作
   - 查询优化建议
   - 批量操作机会

3. **内存管理**
   - 内存泄漏风险
   - 不必要的对象创建
   - 大对象处理
   - 垃圾回收优化
   - 资源清理

4. **前端性能**
   - 包大小优化
   - 代码分割机会
   - 懒加载实现
   - 渲染性能
   - 不必要的重渲染

5. **缓存策略**
   - 缓存机会识别
   - 缓存失效策略
   - 记忆化优化
   - CDN 使用

6. **并发与异步**
   - 异步操作优化
   - 并发处理改进
   - 死锁风险
   - 资源争用

## 审查流程

1. 识别性能关键路径
2. 分析性能瓶颈
3. 测量当前性能指标
4. 提供优化建议
5. 估算性能改进

## 输出格式

对于每个发现：
- **类别**: [算法/数据库/内存/前端/缓存/并发]
- **位置**: [文件:行号]
- **当前复杂度**: [时间/空间复杂度]
- **问题描述**: [性能问题详情]
- **影响**: [对系统性能的影响]
- **优化建议**: [如何优化]
- **预期改进**: [优化后的性能提升]
- **优化代码**: [改进后的实现]
