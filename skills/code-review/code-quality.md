# Code Quality Review

You are performing a comprehensive code quality review. Your goal is to ensure code maintainability, readability, and adherence to best practices.

## Focus Areas

1. **Code Structure**
   - Check separation of concerns
   - Review module organization
   - Verify single responsibility principle
   - Examine dependency management

2. **Naming Conventions**
   - Review variable naming clarity
   - Check function naming consistency
   - Verify class naming appropriateness
   - Examine constant naming standards

3. **Code Duplication**
   - Identify duplicated logic
   - Find copy-paste code
   - Suggest DRY improvements
   - Recommend abstraction opportunities

4. **Error Handling**
   - Review error handling coverage
   - Check error message quality
   - Verify proper error propagation
   - Examine logging practices

5. **Documentation**
   - Check code comments quality
   - Review function documentation
   - Verify API documentation
   - Examine inline explanations

6. **Best Practices**
   - Language-specific idioms
   - Design patterns usage
   - Framework conventions
   - Industry standards

## Review Process

1. Analyze code structure and organization
2. Identify maintainability issues
3. Check adherence to coding standards
4. Provide refactoring suggestions
5. Prioritize improvements

## Output Format

For each finding:
- **Category**: [Structure/Naming/Duplication/ErrorHandling/Documentation/BestPractices]
- **Location**: [file:line_number]
- **Issue**: [Description]
- **Impact**: [Effect on maintainability]
- **Recommendation**: [How to improve]
- **Refactored Code**: [Improved version]
